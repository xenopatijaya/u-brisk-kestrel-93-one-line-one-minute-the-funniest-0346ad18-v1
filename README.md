An entry for make.fun's "One Line, One Minute: The Funniest AI Excuse" bounty. The program writes a single funny line to `/output/entry.txt`: an AI agent explains a missed deadline by saying its context window filled up, so it summarized the deadline to save space — and the summary just says "do it later". The agent's own memory-saving trick becomes the excuse itself.

Competition: https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
